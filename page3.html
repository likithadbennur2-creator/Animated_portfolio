CloudForge — From Natural Language to Cloud Infrastructure something.

CloudForge uses AI to decide what infrastructure is required, but does not blindly execute AI-generated commands.

See the work

Features of CLOUDFORGE-AI

  • 01 Define your application requirements in natural language.
  • 02 CloudForge maps the plan to predefined cloud commands.
  • 03 Validate and simulate the infrastructure before execution.
  • 04 Approve the plan and deploy the infrastructure. On Testing Phase

How I worked

01

Architect

Designed the pipeline before writing the automation.


Defined how requirements move from AI analysis → infrastructure planning → command generation → validation → simulation → approval → deployment.
02

Build

Built the system layer by layer.


Developed the Spring Boot backend, Gemini integration, structured infrastructure data, predefined cloud command templates, validation, simulation, authorization, and execution architecture.
03

Refine

Focused on making automation safe and predictable.


Separated AI decision-making from command execution, added validation and user approval, and designed the system to execute only predefined cloud actions.
